# Desafío de Sistemas de Ecuaciones – 4to C

Juego multijugador en tiempo real con Node.js, Express y Socket.IO.

## Ejecutar

```bash
npm install
npm start
```

El servidor usa `PORT` si la plataforma de hosting lo proporciona. La música `Married Life.mp3` se puede añadir en `public/`.

## Incluye

- Salas con código EC-xxxxx
- QR para compartir la sala
- Jugadores y animales
- 15 ejercicios de sistemas de ecuaciones
- 3 puntos por respuesta correcta
- Temporizador de 5 minutos
- Clasificación y pantalla final
